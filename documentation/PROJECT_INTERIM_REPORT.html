SALES DATA ANALYZER 2

Abstract

The Sales Data Analyzer is a console-based Python application designed to analyze retail sales transaction data from CSV files. The system allows users to clean raw records, compute summary statistics, group sales by product and region, and display the top 5 selling products. Sales records are stored in a Pandas DataFrame during program execution, and the analytical results are visualized using Matplotlib charts.

The project is an applied Data Analytics and Python programming application built using Python 3. It applies Pandas for structured tabular data manipulation, data cleansing routines for detecting and skipping invalid rows, groupby operations for categorical aggregation, and Matplotlib for plotting graphical distributions.

Each transaction record includes a date, product name, geographic region, quantity sold, and total sale amount. The program validates numeric fields so that amounts and quantities must be valid numbers, and it filters out corrupted rows (such as text values in numeric fields) as well as duplicate rows. The scope is intentionally clean, modular, and suitable for a college-level project submission.

SALES DATA ANALYZER 3

Introduction

Sales transaction analysis is a fundamental real-world application where information about commercial transactions, item quantities, and regional performance must be maintained and evaluated accurately. A basic business analytics system should allow raw sales data to be ingested and should support common operations such as calculating total turnover, grouping sales by categories, and visualizing trends.

This project demonstrates these operations on a practical scale through a menu-driven Python console application. The user selects an option from the menu, enters the dataset path, and the program performs the requested data processing operation.

The application is organized into the following parts:

  • Data Ingestion & Cleaning – reads raw CSV records, detects headers, skips invalid rows, and eliminates duplicate entries.
  • Summary Analytics – computes aggregate metrics including total revenue, transaction counts, and total units sold.
  • Product & Region Grouping – utilizes Pandas groupby() to aggregate sales performance across products and regions.
  • Top Products Leaderboard – sorts and displays the top 5 best-selling products by quantity and revenue.
  • Data Visualization – generates and displays publication-quality Matplotlib bar charts and line charts.

SALES DATA ANALYZER 7

Methodology

The system works step-by-step as follows:

  1. The application starts and loads the sales CSV dataset from the specified file path.
  2. The system inspects the file header and instantiates an in-memory Pandas DataFrame.
  3. For data validation, each row is checked to ensure that Amount and Quantity are valid numeric values.
  4. If an invalid value is detected (e.g. non-numeric string 'abc'), an informative skip notice is displayed and the row is excluded.
  5. Duplicate rows containing identical records are detected and removed to prevent skewed calculations.
  6. The user selects an operation from the interactive console menu (Options 1 to 5).
  7. For Option 1 (Summary), the program aggregates gross revenue, transaction counts, and total units sold.
  8. For Option 2 (Grouping), the program applies groupby() across Product and Region, then displays the Region-wise bar chart.
  9. For Option 3 (Top Products), the program sorts items by total units sold and presents the top 5 leaderboard.
  10. For Option 4 (Sales Trend), the program computes daily revenue totals and renders a chronological line plot, terminating cleanly on Option 5.

Implementation

The system is implemented as a single-file Python 3 application (sales_analyzer.py) using a clean, procedural, function-based architecture. This eliminates unnecessary object-oriented overhead while ensuring optimal readability for academic evaluation and viva presentation.

Core Functions Breakdown

  • load_data(file_name): Reads the CSV dataset using pd.read_csv() as raw strings. Validates each row: converts Amount to float and Quantity to integer using try...except ValueError. If non-numeric text (such as 'abc') is found, it prints an alert and skips that row. It also uses a Python set of tuples to eliminate duplicate transactions.
  • show_summary(df): Calculates gross revenue via df['Amount'].sum(), total transactions via len(df), and total units via df['Quantity'].sum(). Identifies the top-selling product using .idxmax().
  • show_grouping(df): Applies Pandas groupby() across Product and Region, displays pipe-separated summaries, and plots an interactive Matplotlib bar chart (Region-wise Sales).
  • show_top_5(df): Groups transactions by product, sorts in descending order of total units sold, and displays the top 5 product rankings.
  • show_trend(df): Groups revenue by date and plots a chronological line chart (Daily Sales Trend).
  • main(): Implements a clean while True: loop providing a 5-option interactive console menu.

Time Complexity Analysis

Let N be the number of rows in the CSV file, and K be the unique product count:

  • CSV Parsing & Cleaning: O(N) because each record is inspected and validated in a single pass.
  • Summary Calculation: O(N) single-pass aggregation over cleaned numerical columns.
  • Product & Region Grouping: O(N) using optimized hash-based grouping in Pandas.
  • Top 5 Product Ranking: O(K log K) where K is the number of distinct products.
  • Chart Plotting: O(K) for the categorical bar chart, and O(D) for the chronological line chart.
