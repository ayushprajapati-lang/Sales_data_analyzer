PS No.        : 9
Project Title : Sales Data Analyzer

Problem Statement:
Analyse a sales CSV file to find total revenue, best-selling products and 
region-wise performance using grouping, and visualise the results.

Language : Python 3
Concepts : Pandas, CSV, Matplotlib, Grouping

Note: CSV columns: Date, Product, Region, Quantity, Amount

--------------------------------------------------------------------------------
TEST CASES / CASE STATEMENTS (4 cases)
--------------------------------------------------------------------------------

Test Case 1: Normal Input
INPUT:
  sales.csv:
  2026-08-01,Laptop,North,2,100000
  2026-08-02,Mouse,South,10,5000
  2026-08-03,Laptop,South,1,50000
  Menu option 1 (Summary)
EXPECTED OUTPUT:
  Total Revenue: 155000 | Transactions: 3 | Units sold: 13

Test Case 2: Boundary / Minimum Input
INPUT:
  sales.csv: 1 row only
  2026-08-01,Mouse,North,1,500
  Menu option 1 (Summary)
EXPECTED OUTPUT:
  Total Revenue: 500 | Transactions: 1 | Top product: Mouse

Test Case 3: Invalid Input
INPUT:
  sales.csv:
  2026-08-01,Laptop,North,2,100000
  2026-08-02,Mouse,South,10,abc
  2026-08-03,Laptop,South,1,50000
EXPECTED OUTPUT:
  Row 2 skipped: invalid Amount 'abc'
  Total Revenue: 150000 | Transactions: 2

Test Case 4: Different Valid Scenario
INPUT:
  Same CSV as Test Case 1
  Menu option 2 (Group by Product & Region)
EXPECTED OUTPUT:
  Laptop: 150000 | Mouse: 5000
  North: 100000 | South: 55000
  Bar chart 'Region-wise Sales' displayed

5. Plot at least two Matplotlib charts (bar and line).
